# 무무가리킴 — 가리키는 말의 탑

초등 국어 "가리키는 말(지시어)"을 거리 관계로 익히는 게이미피케이션 학습 웹앱.
하나의 탑을 층층이 쌓아 올리며 이것·그것·저것을 정확히 가려 쓰는 감각을 기른다.

## 교육 설계

지시어는 **거리 3분법**으로 통일된다.

| 구분 | 위치 | 사물 | 장소 | 꾸미는 말 |
|---|---|---|---|---|
| 근칭 | 말하는 사람 가까이 | 이것 | 여기 | 이 + 명사 |
| 중칭 | 듣는 사람 가까이 / 이미 말한 것 | 그것 | 거기 | 그 + 명사 |
| 원칭 | 둘 다에게서 멀리 | 저것 | 저기 | 저 + 명사 |

계통(지시대명사 → 지시관형사, 구체 → 추상)에 따라 탑을 3개 층으로 쌓는다.

- **1층 · 사물** — 이것 / 그것 / 저것
- **2층 · 장소** — 여기 / 거기 / 저기
- **3층 · 꾸미는 말** — 이 / 그 / 저 (+ 명사)

각 층 안에서 4개 게임 모드를 순차로(인식 → 이해 → 맥락 → 산출) 밟아 한 층을 완성한다.

1. **장면 보고 고르기** — 화자·청자·사물 배치를 보고 알맞은 말 고르기 (거리 인식)
2. **관점 바꾸기** — 같은 사물도 말하는 사람이 바뀌면 말이 바뀜을 체험 (상대성 이해)
3. **대화 빈칸 채우기** — 앞에서 말한 것을 다시 가리키기 (화맥지시 / 맥락)
4. **문장 만들기** — 장면에 맞는 말을 골라 한 문장 완성 (산출)

3층 꼭대기까지 오르면 **마스터피스 완성**.

## 기술

- **스택**: Vanilla HTML + CSS + JS (빌드 없음)
- **저장**: `localStorage` 키 `mumudirection.progress.v1` (완료한 층·모드 집합)
- **소리**: Web Audio API (자산 없는 효과음)
- **디자인**: 네오브루탈리즘 (굵은 검정 테두리 · 하드 오프셋 그림자 · 쨍한 색면)
- **자산**: 무무·친구·사물은 이모지로 표현 → 무자산·오프라인 동작

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 골격 (랜딩 · 탑 · 게임 · 축하) |
| `styles.css` | 디자인 토큰 · 레이아웃 |
| `data.js` | 층×모드별 문항, 거리 어휘표, 무무 대사 |
| `tower.js` | 탑 렌더링 · 진행 저장/복원 · 라우팅 · 소리 |
| `game.js` | 4개 모드 컨트롤러 · 정답/피드백 |

## 실행

빌드가 필요 없다. 정적 서버로 열면 된다.

```bash
python -m http.server 5180
# http://localhost:5180
```

`index.html`을 브라우저에서 바로 열어도 동작한다(USB 전달 가능).

## 접근성

- 버튼 최소 48×48px, 키보드만으로 전 기능 사용 가능
- 정답 피드백은 소리 + 시각 동시 제공
- `prefers-reduced-motion` 존중, 360px 폭 대응
- 명도 대비 WCAG AA (검정 글자 / 쨍한 색면)
